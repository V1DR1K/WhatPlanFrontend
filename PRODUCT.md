# WhatPlan
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Couples sharing places, films, cooking, activities, important dates and journeys. Content is private to each couple and editable by both active members.
## Product Purpose
Keep reusable catalogs and dated experiences together, with photos and reviews. Plan and remember trips without duplicating existing places, films or recipes.
## Operating Context
Spanish interface, responsive mobile and desktop web. Origin city is shared by the couple; catalogs filter by city while Whither Journey groups plans and experiences by trip and destination stage.
## Capabilities and Constraints
React 19 / TypeScript, Spring Boot 3.5 / Java 21, PostgreSQL with couple isolation. Journeys have multiple destinations, daily agenda, private files, stays, per-person packing and balances separated by currency. Existing records belong to Rosario, Argentina.
## Brand Commitments
Preserve the incumbent dark visual system and section accents. Whither Journey uses a light-blue accent and travel/airplane imagery. Reuse the current controls, typography and navigation.
## Accessibility & Inclusion
Keyboard operable forms and agenda ordering; respect reduced motion and provide responsive layouts.
